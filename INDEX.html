🚀 Como Começar

Passo 1: Clonar Projeto

Via Git: git clone https://github.com/seu-usuario/TCC-IPES.git cd "TCC MILTON" Ou manualmente:

Baixe arquivo .zip do repositório e extraia em C:\Users\seu-usuario\Downloads\

Passo 2: Setup Ambiente

  1. Abra PowerShell como Admin
    • Windows + X → "Windows PowerShell (Admin)"
    • Ou: Right-click em PowerShell → "Run as administrator"
  2. Navegue para pasta projeto: cd "C:\Users\jotac\Downloads\TCC MILTON"
  3. Execute setup: .\setup_tcc_ipes.ps1
    • Script vai verificar Python
    • Script vai baixar R-4.3.3 (5-10 min)
    • Script vai instalar pacotes maxnet/ecospat (3-5 min)
    • Aguarde até ver "✅ SETUP COMPLETO"

Passo 3: Verificar Setup

Abra dashboard para verificar:
  • ✅ Python ≥ 3.8
  • ✅ R ≥ 4.0
  • ✅ Diretórios projeto (R28, R29, R30, R31)

→ Abrir Dashboard

Passo 4: Executar Skill

Após setup completo, execute: python skill_modelagem_ipes.py
  • R28 (6 modelos básicos): ~1 hora
  • R30 (72 modelos grade): ~2 horas
  • R31 (validação externa): ~1 hora
  • Total: ~4-5 horas
