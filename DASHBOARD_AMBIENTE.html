❌ Problema: R não encontrado

R é obrigatório para executar modelos MaxEnt (R28-R31). Sem R, skill não funciona.

📥 Solução 1: Instalar R (Windows)
  1. Acesse: https://cran.r-project.org/
  2. Clique: "Download R for Windows"
  3. Baixe: "R-4.3.3-win.exe" (ou versão mais recente)
  4. Execute: instalador (use defaults)
  5. Reinicie: seu computador

⏱️ Tempo: ~5-10 minutos (depende da internet)

📦 Solução 2: Instalar Pacotes R (Obrigatório)

Após instalar R, abra PowerShell/CMD e execute:

Rscript -e "install.packages(c('maxnet','ecospat','raster','sp'))"

⏱️ Tempo: ~3-5 minutos (download pacotes)
ℹ️ Pode pedir "Update packages?" → responda n (não atualizar)

✅ Solução 3: Testar Instalação

Após instalar, execute no PowerShell:

Rscript --version

Se aparecer versão R, está OK! Próximo: execute skill novamente.
